# FS93 — Comm-Link: no Safari zoom + D-pad field navigation

## Purpose

On Join **Comm-Link**, focusing inputs must **not** zoom Safari. Users navigate **alias → contact → Transmit** with the Game Boy **D-pad** and confirm with **A**.

## Desired `{functionality}`

1. Focus/type on alias or email/phone without viewport zoom-in.  
2. D-pad up/down (and optionally left/right) cycles focus: alias, contact, Transmit.  
3. A focuses/activates: inputs get focus; Transmit submits.  
4. B still backs out of join (FS92).  
5. Visual focus remains clear.

## Acceptance

| ID | Result |
|----|--------|
| A1 | Focus input on iOS Safari → no page zoom |
| A2 | D-pad moves among three controls |
| A3 | A on Transmit submits when valid |
| A4 | B still closes join / back stack |

# Ticket 005: Diegetic Retro RPG Dialogue Box Stage Integration & Typewriter Presentation

## Question
How is the prototype dialogue box (`retro_rpg_dialogue_box.html`) ported into an authentic, stage-contained React component (`src/components/RetroRpgDialogueBox.tsx`) with gold pixel font (`#f7ca18`), metallic portrait frame (`talk.png`/`sit.png`), 30–40ms typewriter animation with punctuation pauses, bouncing downward prompt arrow, and click-to-advance dismissal?

## Context & Specification Grounding
- **Governing Specification:** `functional_specification_109.md`
  - §Desired Functionality (5): "The dialogue generated by the Hugging Face node must render in the retro RPG dialogue window on the game screen."
  - §Desired Functionality (5): "Speaker Name: Displayed in gold pixel font (`#f7ca18`) with black drop shadow."
  - §Desired Functionality (5): "Portrait Display: Displays the seated patron's facial portrait (`talk.png` or `sit.png`) within the metallic beveled frame."
  - §Desired Functionality (5): "Animated Typewriter: Characters appear incrementally at authentic retro speeds (30–40ms/char) with natural pauses at punctuation."
  - §Desired Functionality (5): "Prompt Arrow: An animated bouncing downward triangle appears upon typewriter completion."
  - §Desired Functionality (5): "Click-to-Advance: Clicking anywhere on the dialogue box instantly completes in-flight text or dismisses the completed box."
  - §Acceptance Criteria (AC5 & AC6): "Dialogue displays with matching styling from `retro_rpg_dialogue_box.html`: dual white border, corner loops, silver portrait frame, gold speaker name, and bouncing prompt arrow. Text renders character-by-character at 30–40ms cadence, with punctuation delays, and immediate completion upon click."

## Codebase Audit & Technical Discrepancy Analysis

### 1. Prototype Isolated in Static HTML Demo
`retro_rpg_dialogue_box.html` exists in the repository root as an isolated HTML demo file with hardcoded Caesar portrait and text, not integrated as a React component.

### 2. Available Font and Pixel CSS
`src/app/layout.tsx` (L22–L26, L48) already imports and configures the authentic pixel font `Press_Start_2P` with CSS variable `--font-press-start`.

### 3. Stage Container Alignment
In `src/app/page.tsx`, the game scene renders inside `.pov-stage` wrapped in `PovStageShell`. Any diegetic in-world HUD component must be positioned over `.pov-stage` with high z-index (e.g. `z-index: 50`) so it scales with the retro stage and does not collide with floating receipt paper or carousels.

## Architectural Decisions to Lock

### 1. Dedicated React Component (`src/components/RetroRpgDialogueBox.tsx`)
- Export component with strict props:
  ```typescript
  export interface RetroRpgDialogueBoxProps {
    isOpen: boolean;
    speakerName: string;
    portraitSrc: string;
    message: string;
    onAdvance?: () => void;
    onDismiss?: () => void;
    speedMs?: number; // default 35ms
  }
  ```
- Component state:
  - `displayedText`: string
  - `isTyping`: boolean
  - `showPromptArrow`: boolean
- Typewriter cadence:
  - Base interval: 35ms per character.
  - Punctuation pause: additional 120ms delay when encountering `.`, `!`, `?`.
- Click interaction handler:
  ```typescript
  const handleClick = () => {
    if (isTyping) {
      // Instant reveal
      clearTypewriterTimer();
      setDisplayedText(message);
      setIsTyping(false);
      setShowPromptArrow(true);
    } else {
      // Advance or dismiss
      onAdvance?.();
      onDismiss?.();
    }
  };
  ```

### 2. Diegetic Pixel Styling Parity (`src/components/RetroRpgDialogueBox.module.css`)
- Replicate exact CSS rules from `retro_rpg_dialogue_box.html`:
  - Font family: `var(--font-press-start), 'Press Start 2P', monospace`.
  - Window background: `#09133b` (navy).
  - Double border: `border: 3px solid #ffffff; outline: 2px solid #000000; box-shadow: inset 0 0 0 3px #09133b, inset 0 0 0 5px #ffffff, 0 8px 24px rgba(0, 0, 0, 0.7);`
  - Portrait frame: `#060b1c` background, `#cbd5e1` 3px border, metallic inset shadows (`inset 2px 2px 0px #ffffff, inset -2px -2px 0px #475569`).
  - Corner scrollwork loops: 4 absolute positioned SVGs matching the pixel matrix in `retro_rpg_dialogue_box.html`.
  - Speaker Name: `#f7ca18` gold text with `2px 2px 0px #000000` drop shadow.
  - Prompt Arrow: SVG downward triangle with `@keyframes retro-bounce` (0.75s steps(2, jump-none) infinite).

### 3. Stage Mounting & Concurrency Wiring (`src/app/page.tsx`)
- In `src/app/page.tsx`, derive current dialogue from `activeDialogueSeat`:
  ```tsx
  {activeDialogueSeat && seatOrders[activeDialogueSeat] && (
    <RetroRpgDialogueBox
      isOpen={true}
      speakerName={requireCharacter(seatOrders[activeDialogueSeat].characterId).displayName}
      portraitSrc={
        talkSrcForCharacter(seatOrders[activeDialogueSeat].characterId) ||
        sitSrcForCharacter(seatOrders[activeDialogueSeat].characterId)
      }
      message={
        seatOrders[activeDialogueSeat].status === 'rejected'
          ? (rejectionDialogues[activeDialogueSeat] || 'IMPROPERLY PREPARED!')
          : (seatOrders[activeDialogueSeat].orderDialogue || 'AWAITING ORDER...')
      }
      onDismiss={() => setActiveDialogueSeat(null)}
    />
  )}
  ```
- Position inside `PovStageShell` pinned to the bottom of the visible stage (`bottom: 16px; left: 16px; right: 16px; z-index: 50; max-width: 680px; margin: 0 auto;`).
- When a patron departs, dismiss active dialogue for that seat immediately.

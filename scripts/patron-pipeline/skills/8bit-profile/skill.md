## Core Framing Prompt

When generating a profile character image, use this exact framing:
Create a right-side torso profile of the person in the image generated by {/8bit-headon}. Bust from head through upper chest. Keep likeness. Full figure not required.
text## Stylization

Do **not** hard-code 8-bit / 16-bit instructions here.  
Instead, always activate and apply the `{/8bit-style}` skill (8bit-character-style) for all stylization, background, isolation, and visual constraints.

## Instructions

1. Apply the Core Framing Prompt above as the pose and crop instruction.
2. Use the image previously generated by the `{/8bit-headon}` skill as the reference/source image.
3. Immediately load and follow the `{/8bit-style}` skill for the full visual treatment (8-bit/16-bit video-game style, pure tan background, isolation rules, readability, forbidden styles, etc.).
4. Keep the character recognizably based on the head-on image while transforming it under the 8bit-character-style rules.
5. Output only the isolated right-side profile bust on the solid tan background required by the style skill.

## When to Activate

- User requests a profile shot, right-side torso, or side view of a character/patron.
- After a head-on character has been generated and a matching profile is needed.
- Any request that pairs a head-on result with "profile" framing.
